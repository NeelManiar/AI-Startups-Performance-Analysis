# AI Startup Performance Analysis

A data analysis project exploring the **financial, operational, and customer performance of AI startups** using Python.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 📊 What I Analysed

The project explores 7 questions related to:

* Funding and financial performance
* Revenue and profitability
* Correlation between Customer satisfaction and Churn
* Profitability of AI Models 
* Industry-wise startup performance
* External Factors like Company Age and Size

The analysis uses **data cleaning, aggregation, correlation analysis, and visualisation** to identify meaningful patterns in the dataset.

## 📁 Dataset

The dataset contains information about AI startups, including:

`Company` · `Country` · `Industry` · `Employees` · `Funding` · `Monthly Users` · `AI Model` · `Inference Cost` · `Customer Churn` · `Customer Satisfaction` · `Revenue` · `Profit`
P.S. Given by ChatGPT

## 🎯 Objective

To use exploratory data analysis to understand **what factors are associated with stronger performance among AI startups** and develop practical data-science skills.
